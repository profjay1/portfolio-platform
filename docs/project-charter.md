Portfolio Platform Project Charter
Project Name

Professional Portfolio Platform

Project Goal

To build a full-stack portfolio website that presents my skills, projects, resume, and professional identity as an emerging full-stack Java software engineer.

Target Users

Recruiters, hiring managers, clients, and myself as the admin user.

Core Features

Public homepage, about section, skills section, project showcase, project case study pages, contact form, resume download, admin login, admin dashboard, and project management.

Technology Stack

Angular, TypeScript, Spring Boot, Java, PostgreSQL, Docker, GitHub Actions, and AWS.

Success Criteria

The website must be responsive, the backend API must work correctly, projects must be manageable from the admin dashboard, the application must be deployed online, and the GitHub repository must be clean and documented.
